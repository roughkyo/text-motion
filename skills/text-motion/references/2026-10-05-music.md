# 음악 후보

## 필수 추천 기준

상업적 무료 이용, 원문 주제 적합성, 묵직하고 트렌디한 urban 힙합 비트를 함께 확인한다. 저음/808 또는 킥의 무게감, 드럼 그루브와 현대적인 프로덕션을 청취 판단의 단서로 삼되 특정 악기나 BPM을 필수값으로 고정하지 않는다. 슬픔·진지함·밝음 등 원문 분위기에 맞는 힙합을 찾고, 일반 corporate 음악으로 바꾸지 않는다.

최대 3곡만 제시한다. 적합한 곡이 없으면 빈 목록과 이유를 전달한다. 곡 페이지·공식 라이선스 확인은 법적 보증이 아니며 음악 단독 재판매/재배포와 제3자 권리 제한을 확인한다. 상업적 무료 이용 가능성과 Content ID 알림 가능성은 별도로 표시한다.

`metadata_only`는 태그·설명만 확인한 청취 검증 전 후보다. 추천 확정처럼 표현하지 않는다. 브라우저에서 사용자가 직접 듣고 사운드를 확인해야 선택할 수 있다. 실제 들은 경우에만 `listened`, 사용자가 확인한 경우에만 `user_confirmed`를 기록한다. 아래 JSON의 문구와 URL은 형식 설명이며 실제 곡이 아니다.

공식 안내: [음악](https://pixabay.com/ko/music/), [라이선스](https://pixabay.com/service/license-summary/), [FAQ](https://pixabay.com/service/faq/), [API](https://pixabay.com/api/docs/).

2026-10-05 확인: 음악 상세 페이지에서 재생·무료 다운로드·Content ID 등록 표시를 확인할 수 있다. 다운로드한 음악은 영상과 결합하여 사용한다. 음악 자체를 이 스킬의 재배포 자산으로 번들하지 않는다. 라이선스와 Content ID는 서로 다른 항목이며 Content ID 등록 음악은 게시 후 청구가 생길 수 있다.

곡 후보 JSON은 다음 구조를 사용한다. 사용자 파일 이름이나 원문은 외부 검색에 전달하지 않는다.

```json
{
  "topic": "기술·AI·IoT",
  "checked_at": "2026-10-05",
  "candidates": [
    {
      "title": "공식 페이지에 있는 제목",
      "artist": "공식 작곡가 표시",
      "url": "https://pixabay.com/music/실제로-확인한-상세-페이지/",
      "duration": "2:00",
      "content_id": "registered 또는 not_displayed 또는 unknown",
      "reason": "공식 태그/설명에 근거한 주제 적합성",
      "topic_match": true,
      "commercial_use": {
        "free": true,
        "license_url": "https://pixabay.com/service/license-summary/",
        "checked_at": "2026-10-05",
        "evidence": "곡 상세 페이지와 공식 라이선스를 확인한 상업적 무료 이용 근거 및 제한"
      },
      "sound": {
        "style": "urban_hiphop",
        "status": "metadata_only",
        "reason": "urban/hiphop/heavy bass 등 공식 태그 근거. 묵직함·트렌디함은 청취 검증 전"
      },
      "basis": "page_metadata 또는 listened",
      "checked_at": "2026-10-05"
    }
  ]
}
```

현재 주제와 무관한 데모 후보를 자동 추천으로 표시하지 않는다. 새 소스파일로 바꾸면 이전 후보 선택·연결 음악·최종 확인을 지운다. 공식 페이지의 듣기 버튼은 외부 링크이고 앱 내부 스트리밍이 아니다. 연결한 로컬 파일은 앱 내부 플레이어로 들어볼 수 있다.
