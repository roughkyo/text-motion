## 타이밍·문구

- 빈 줄은 장면 구분, 한 줄바꿈은 같은 장면의 줄. 각 장면에 동작 종류와 퇴장 종류를 저장한다.
- 기본은 요청한 속도감에 맞춘 `tight`. 샘플 본래의 더 느린 리듬을 원하면 `standard`.
- 표준 등장 기준: 파일별 0.30~0.90초; 강화는 0.85배(2026-10-06, 0.68배는 등장이 0.2초 안팎으로 끝나 샘플 차이가 보이지 않았다). 줄이 많으면 줄 지연 공간을 확보한다.
- 읽기 유지 하한은 글자 수에 따라 계산한다. 짧은 제목 0.22초부터, 강화는 가시 글자수/17초, 표준은 /12초를 사용한다. 이는 시작값이지 독해 보증이 아니다.
- 15초 영상은 보통 10~14개 짧은 키워드/문구를 먼저 설계한다. 모든 샘플을 이 개수로 강제하지 않는다.
- 한글 2~6자 키워드와 6~14자 설명을 번갈아 배치한다. 문구를 추가할 때 반드시 원문 근거가 있어야 한다.
- 짧은 내용을 15초로 늘려 긴 정지를 만드는 입력은 오류로 돌린다. 원문에서 더 추출하거나 문구를 의미 단위로 재편집한다.
- 반대로 문구가 과하면 타이핑을 읽지 못할 정도로 빠르게 하지 말고 문구를 줄인다.
- 엔진은 텍스트를 임의 삭제·요약하지 않는다. 범용스킬이 편집한 문구를 전달하고 보존 검사를 한다.

## 음악 반응과 추정의 한계

기존 분석은 오디오 스트림 존재만 확인했고 스네어를 분석하지 않았다. 이번에는 10개 원본 전체 음원을 22,050Hz로 디코딩하고 1024샘플 FFT / 220샘플 간격으로 대역별 스펙트럼 증가량을 측정했다. 저역 35~180Hz는 킥 후보, 중고역 650~6500Hz와 몸통 대역 180~2500Hz는 스네어 후보다. 악기 분리/정답 라벨 검증이 아니며 하이햇·보컬·효과음이 섞일 수 있다.

원본에서 확인했던 큰 명도 전환 35개와 자동 스네어 후보의 최근접 시각은 80ms 이내 8개, 150ms 이내 18개였다. 이는 '모든 원본이 매 스네어에 반전한다'는 근거가 아니다. 검출 누락·오탐 가능성도 있어 '나머지는 비트와 무관하다'고 단정하지 않는다.

강화 모드의 제작 규칙:
- 사용자 선택 음원을 분석한다. 원본 음원의 박자를 새 음원에 그대로 사용하지 않는다.
- 컷은 ±0.12초 안의 실제 검출 피크로만 스냅한다. 앞뒤 읽기 하한이 깨지면 이동하지 않는다.
- 킥 후보에 0.18초 이내 감쇠하는 최대 약5.5% 스케일 펄스.
- 배경 색은 [원본 배경 시간표](2026-10-05-background-flow.md)를 따른다. 스네어 후보로 전체 색 극성을 전환하지 않는다.
- 연기 샘플에는 도형 파편을 추가하지 않는다. 파편은 57032891·62999763에만 쓰는 장식이며 색은 해당 샘플 팔레트를 따른다. 모든 샘플에 같은 파편을 넣지 않는다.
- 검출 이벤트·강도·음원 해시·분석 방법을 스토리보드 JSON에 저장.
- `standard`는 원본 스타일 위주이며 파편 강화를 적용하지 않는다. `tight`도 원본 배경 흐름을 유지한다.
- 청취·시각 확인 없이 '스네어 완벽 동기화'라고 쓰지 않는다. 잘못 맞는 타격은 분석/이벤트를 보정한 뒤 다시 미리보기한다.

색 반전은 강한 시각 자극이다. 광과민성 안전 인증이 아니며 사용자에게 미리보기에서 확인하도록 안내한다.

## 검증

1. 10개 샘플별 한글 테스트 클립을 실제 렌더링한다. 선택 UI에 이름만 있는 프리셋으로 끝내지 않는다.
2. 문구 보존, 최소 시간, 정확한 총 길이, 결정론적 프레임, 원본 배경 상태 대응, 연기 무반전·타이핑 박스 격리를 검사한다.
3. 알려진 합성 타격 시각과 자동 검출 시각의 오차를 검사한다. 이것을 실제 음악 악기 분류 정확도로 제시하지 않는다.
4. 장면 초기/정착/퇴장 연속 프레임과 음악 포함 30fps 클립을 검토한다.
5. 미리보기는 최종과 같은 `project_frame` 및 음원/시간표를 사용한다. 음원 교체·내용 수정 후 새 미리보기 완성 전 최종 승인 차단.
6. MP4 해상도·fps·길이·오디오·전체 디코딩 확인과 미적 유사성 판단을 분리한다.

## 연기 배경 에셋

60608725·60806086의 원본을 수정하지 않고 시간·공간 필터로 문자를 제거한 파생 배경 MP4 2개를 사용한다. `scripts/2026-10-05-build-backgrounds.py`로 재생성한다. 실제 원본의 전체 연기 진행은 유지하지만 세부 질감·밝기는 부드럽고 어둡게 변한다. 원본의 깨끗한 배경 레이어를 복원한 것은 아니다. 중앙만 처리한 사각 패치 및 짧은 구간 왕복 시험안은 제외했다. 배경 음원은 사용하지 않고 선택 곡만 합성한다. 2초 단위 디코딩 캐시로 메모리를 제한하고 원본 전체 시간축을 출력에 한 번만 대응한다. 자세한 내용은 [배경 규칙](2026-10-05-background-flow.md)을 따른다.

남는 한계: 원본 전용 폰트/3D/리본 플러그인을 그대로 복원한 것은 아니다. 실제 한글 폰트가 다르면 두께·자폭이 다르다. 무조건 '완벽 재현'이나 '원본 그대로'로 설명하지 않는다.
