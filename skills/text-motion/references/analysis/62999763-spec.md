# 62999763 프레임 단위 사양 (24fps, 840프레임, 35.0초)

판독 근거: 1프레임 단위 시트 18장(주요 구간 전수 + 3장 간격 확인).

## 전역 특징
- **배경 3종을 하드컷으로 교체**: ① 흐린 보케(청록·보라·주황 큰 원형 빛 덩어리, 아주 흐림) ② 순검정/남색 검정(왼쪽 위 약한 청록광) ③ 흰색. 하단 중앙 0.93H에 얇은 회색 가로선(진행 막대 느낌) 상시.
- **서체**: Inter/SF 계열 그로테스크 볼드. 흰색, 흰 배경에서는 남색(#3a3aa0)→검정.
- **24fps 1초 리듬**: 장면 대부분 24~48프레임. 문구는 한 단어~짧은 구.
- **핵심 장치 5종**
  1. **슬롯 머신 첫 글자**: 첫 글자가 알파벳을 역순으로 1프레임씩 넘기며 바뀌다 멈춤(O→N→L→K→J→H→G→E→D, f24–f32 / I→H→G→F→E→D→C→B→A, f120–f128). 단어 전체 위치도 아래에서 올라오며 정착.
  2. **분산 글자 조립**: 글자가 **화면 밖까지 흩어진 거대한 크기·제각각 위치(위·아래·좌우)**에서 시작해 0.5초 동안 제자리로 모임. 첫 글자 앞에 **같은 색의 긴 직사각형 막대**가 붙어 있다가 짧아지며 사라짐(Make f264–f283, Fast f384–f400). 색은 장면마다(흰 배경 남색 / 검정 배경 분홍→보라 가로 그라데이션).
  3. **위로 쌓이는 블러 슬라이드**: 작은 회색 블러 단어가 아래에서 올라와 커지며 선명(Motion f0–f12, 남보라 그라데이션).
  4. **넓은 자간 단어 교체**: 다음 단어가 오른쪽 화면 밖에서 넓은 자간·블러로 들어와 좁혀지며 정착, 이전 단어는 그대로(flows → with, f493–f515).
  5. **블러 글로우 교체**: 강조 단어가 강한 색 블룸(파랑 #3080ff → 분홍 → 보라)으로 등장, 앞 단어는 흰색으로 글자별 타이핑(Our We…Site, f630–f660).
- **문장 끝 점 커서**: 문장 뒤 작은 원(청록→초록)이 세로 막대 ↔ 점으로 모양을 바꾸며 깜빡임(Create with new tools•, Style and work flow•).
- **배경 전환 = 문장 이어붙이기**: 흰 배경으로 하드컷될 때 같은 문장에 단어가 하나 더 붙고 색이 남색→검정으로 0.3초 동안 바뀐다(About time → About time to, f137–f148 / flows with → flows with the, f516–f525).
