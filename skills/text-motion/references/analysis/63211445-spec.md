# 63211445 프레임 단위 사양 (30fps, 1380프레임, 46.0초)

판독 근거: 1프레임 단위 시트 11장 전체(정지 구간이 많아 타일 366개).

## 전역 특징
- **배경**: 순검정 또는 흰색 하드컷 교체. 하단 0.93H 얇은 회색 가로선 상시.
- **글자**: Inter 계열 그로테스크 미디엄~세미볼드. 검정 배경 흰 글자, 흰 배경 검정 글자.
- **편집기 UI 질감이 핵심**: 글자가 **에디터에서 입력되는 것처럼** 보인다.
  - 타이핑은 **단어 단위로 불규칙한 박자**(단어 하나 붙고 3~10프레임 멈춤, 다음 단어). 글자 단위가 아니다.
  - 문장 전체를 감싸는 **얇은 점선 선택 박스 + 모서리·변 중앙 작은 사각 핸들 8개**가 문장 길이를 따라 늘어난다.
  - 왼쪽 정렬 시작점 고정(x≈0.23W), 문장이 길어지면 **다음 줄로 줄바꿈**(최대 5줄).
- **장면별 '선택 하이라이트' 종류가 다르다**
  1. 점선 박스만(Motion Tools, Ready to setup now)
  2. **연파랑 선택 영역**(#b8d4f8)이 문장 전체 뒤에 칠해짐 + 텍스트 커서(Select text tools are here, Adjustable controls…)
  3. **짙은 회색 박스가 단어마다**(Build it from the ground up…, 흰 배경에서 단어마다 검정 배경 흰 글자 라벨)
  4. **빨강(#f04050) 하이라이트가 최신 단어에만**, 다음 단어가 붙으면 이전 단어는 하이라이트 해제(Highlighted text supports…)
  5. 하이라이트 없이 줄 단위 문단 타이핑(Professionally made…)
- **장면 길이 1.5~5초**, 장면 끝은 1~1.4초 정지 후 하드컷. 배경은 장면마다 검정/흰 교대.
