# 원본 배경 흐름과 텍스트 장식의 분리

배경을 무조건 고정하거나 무조건 반복하지 않는다. **선택된 원본의 흐름을 우선한다.** 빠른 문구와 박자는 유지하되 원본에 없는 배경 반전·선택 박스·그림자를 다른 샘플에서 가져오지 않는다.

## 10개 원본 점검

전체 12,737프레임을 160×90으로 디코딩하고 중앙 글자·하단 출처를 제외한 상하 배경 영역을 측정했다. 전체 흐름 이미지를 함께 확인했다. 밝은 상태 기준은 외곽 RGB 중앙값 평균 150 초과다. 이 분류는 흑백 전환 검사용이며 모든 색 변화나 반복 여부를 대신하지 않는다.

같은 색이 재등장하는 것은 영상 클립이 루프한다는 증거가 아니다. 현재 관찰로 원본들의 주기적 배경 루프를 확정하지 않는다. 엔진은 전체 원본 시간축을 목표 길이에 한 번 대응하며, 임의의 왕복·모듈로 재생을 하지 않는다.

## 실제 엔진 규칙

- `2026-10-05-background-profiles.json`에 원본별 길이, 전체 프레임 수, 밝기 상태 구간, 0.5초 간격 외곽 색 표본 4구역을 저장했다.
- 출력 시간 / 출력 길이 × 원본 길이로 배경의 시간축을 대응한다. 텍스트 컷 스냅과 배경 시간은 독립적이다.
- 비연기 배경은 원본 외곽 색 표본을 보간한 2D 근사다. 흑백 전환은 상태 경계에서 즉시 바꾸며 전환 양쪽을 섞지 않는다. 원본 텍스처·조명을 완전히 복원한 것은 아니다.
- 연기는 `assets/2026-10-05-smoke-*-continuous-clean-v4.mp4`를 사용한다. 전후 시간의 낮은 분위수·공간 필터로 원본 글자를 제거한 파생 영상이며 전체 흐름은 유지하되 세부 연기 질감·밝기는 달라진다. 중앙만 지운 사각 패치와 짧은 구간 왕복 재생은 사용하지 않는다.
- 기본 `tight`라도 스네어 후보마다 전체 색을 뒤집지 않는다. 연기에는 파편을 추가하지 않는다. `tight`는 짧은 문구·컷 타이밍·작은 글자 펄스이지 모든 효과를 일괄 추가하는 모드가 아니다.
- 단순 `type`은 글자 공개·커서다. 박스·핸들·색 채움은 `selection_type` 안에서만 사용한다. 연기 글자에는 그라데이션 음영을 넣지 않는다.

## 검증

1. 원본 상태 구간의 시작·중간·끝과 출력 구간을 비교한다. 변해야 하는 배경을 고정한 결과도 실패다.
2. 연기 프레임은 스네어 후보를 추가해도 색이 뒤집히지 않아야 한다.
3. 정착 시 연기 `type` 알파 마스크는 동일 글자의 일반 마스크와 같아야 한다. 박스·그림자 누출을 검사한다.
4. 최종 MP4를 디코딩해 모든 장면 정착 화면·전환 주변을 확인한다. 배경 글자 잔재와 중앙 패치도 검사한다.
5. 음악 포함 실제 렌더와 테스트용 임시 함수를 구분한다. 납품 영상은 임시 함수 교체 없이 배포 엔진으로 생성한다.
