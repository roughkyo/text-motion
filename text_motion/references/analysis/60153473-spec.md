# 60153473 프레임 단위 사양 (30fps, 763프레임, 25.4초)

판독 근거: 1프레임 단위 시트 19장 전체.

## 전역 특징
- **배경**: 검정 + 중앙 얇은 동심원 2개(반지름 0.16H, 0.45H, 회색 20% 이하, 약간 찢긴 질감) + 상단 중앙 점 3개 + 하단 아주 작은 글자. 원은 장면마다 아주 조금 커졌다 작아진다. 전체에 아주 약한 그레인.
- **글자**: 흰색 둥근 고딕 블랙(Montserrat Black 계열), 모서리에 흰 블룸(글로우). 정착 후 거의 정지, 아주 느린 확대.
- **장면 10개, 각각 완전히 다른 '변형 장치'**로 등장한다. 공통점은 RGB(빨·초·파·노·청록) 색 분리와 강한 블룸.
- **장면 사이**: 3~14프레임 빈 화면(원만 보임). 퇴장은 대부분 하드컷(빈 화면으로 즉시).

## 엔진 재현 요구사항
1. 장면 12개의 등장 장치를 각각 별도 렌더러로: 물결 리본 타이핑, 수직 RGB 잔상, 거대 RGB 분리 기울기, 좌우 RGB 블러 수렴, 외곽선 잔상 줄(점에서 뿜어 나옴), 열화상 블러, 대각선 속도선 타이핑, 픽셀 글리치 조립, 무지개 압출.
2. 글자 흰 채움 + 블룸, 외곽선 모드, 이탤릭(기울기) 모드.
3. 배경: 동심원 2개 + 상단 점 3개 + 그레인.
4. 장면 순서는 원본대로 쓰고, 같은 장치를 연속으로 쓰지 않는다.
