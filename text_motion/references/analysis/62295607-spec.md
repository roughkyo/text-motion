# 62295607 프레임 단위 사양 (60fps, 2178프레임, 36.3초)

판독 근거: 1프레임 단위 시트 33장(주요 구간 전수 + 나머지 3장 간격 확인).

## 전역 특징
- **배경(어두운 모드)**: 남색 검정(#06070f) + **오른쪽 가장자리 세로 청색 광원**(밝은 하늘색 #3a8cff, 폭 0.06W, 세로로 길게 휜 형태, 천천히 숨쉬듯 밝기 변화) + **왼쪽 아래 약한 청색 광**. 아주 약한 그레인. 좌상단 작은 아이콘, 우상단 ◇, 하단 아주 작은 글자.
- **배경(밝은 모드)**: 흰색. 5.45~7.67초, 19.27~21.28초 두 구간(1프레임 전환).
- **글자**: 흰색 기하학 그로테스크 볼드(Gilroy/Poppins 계열), 소문자 위주. 문구는 대부분 **한 단어 또는 짧은 구**.
- **핵심 장치 '거대 반투명 교체'**: 다음 단어가 **화면 폭만큼 큰 반투명 회색**으로 이전 단어 뒤에 겹쳐 나타나고(이전 단어는 작아지며 흐려짐), 큰 단어가 **0.25초 동안 수축하며 회색→흰색으로 선명**해진다(f136–f155, f227–f248, f1881–f1897). 최근 단어는 남색 빛 그라데이션(위 흰→아래 하늘색)으로 시작해 흰색으로 회수.
- **3D 4각 별**: 오목한 변, 두께, 보라·분홍·흰 그라데이션(어두운 모드) / 흑백 크롬(밝은 모드). 화면 중앙에서 회전하며 커졌다 작아지는 오프닝(f4–f60), 흰 화면에서는 문장 뒤에 거대한 크롬 별이 회전하며 겹침(f330–f460), 좌상단·우하단 작은 크롬 별 2개(f1163–f1300).
- **장치 목록**: 거대 반투명 교체, 글자별 아래에서 솟음(마스크, `your` f988–f1005), 글자별 아래로 빠짐(f1037–f1048), 넓은 자간 단어별 타이핑(more expensive, f800–f820), 글자 기울기로 아래로 흘러내림 퇴장(f876–f887), 단어별 회색 페이드 퇴장(Good text design…, f645–f668), 문장 끝부터 사라짐(ing! f2160–f2167), 별 → 점으로 수축 후 문구 등장(f1600–f1637), 두 줄 강조색(파랑) 단어.

## 엔진 재현 요구사항
1. 장면 15개 템플릿(거대 반투명 교체를 중심으로, 흰 화면 구간 2번, 별 등장 3번).
2. 오른쪽 세로 청색 광원 배경, 흰색/어두움 1프레임 전환.
3. 11971627용 3D 별 렌더러를 재사용하되 **크롬 흑백 재질**(밝은 모드)과 보라·분홍 재질(어두운 모드)을 추가.
4. 남색 세로 그라데이션 글자 → 흰색 회수, 파랑 강조 단어.
