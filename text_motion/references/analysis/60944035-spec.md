# 60944035 프레임 단위 사양 (30fps, 1324프레임, 44.1초)

판독 근거: 1프레임 단위 시트 19장 전체 + 원본 해상도(2560×1440) 크롭 4구간(f18–40, f50–66, f722–734, f849–862).

## 전역 특징
- **배경**: 순검정 고정. 화면 전체에 **수평 디지털 노이즈 조각**(짧은 가로 줄무늬·점 덩어리, 회색, 글자 위아래 0.1~0.3H 범위)이 매 프레임 위치를 바꾸며 깜빡인다. 가끔 화면을 가로지르는 얇은 흰 수평선이 1프레임 번쩍인다(f5, f7, f9, f14, f25, f42, f46, f108, f131).
- **상시 레이어**: 좌상단 아주 작은 글자, 우상단 작은 원(○), 좌하단·우하단 작은 글자(원본 문구는 복제하지 않고 사용자 주제로 대체).
- **서체**: 아주 넓은(extended) 초굵은 그로테스크 대문자(Monument Extended/Druk Wide 계열). 한 줄, 화면 중앙(0.5H), 정착 폭 0.40~0.47W. 끝맺음만 일반 폭 볼드(Thank you for viewing).
- **두 상태의 1프레임 교대가 핵심 질감**: ① **흰 채움**(#ffffff) ② **남색 외곽선만**(#2a1bd8 부근, 획 두께 ≈ 글자 높이의 4%, 속은 비어 있음). 두 상태가 불규칙한 1~3프레임 간격으로 번갈아 나온다(스트로브). 등장·퇴장·유지 중간에 모두 쓰인다.
- **슬릿(가로 절단) 전환**: 글자 높이의 일부만 흰 채움, 나머지는 남색 외곽선. 경계선이 위→아래 또는 아래→위로 1~2프레임에 지나간다(f53–f57 등장, f61–f64 퇴장 방향 반대). 경계 바로 위에 얇은 흰 선이 붙는다.
- **잔상 복제**: 장면 전환 때 이전 단어의 남색 외곽선 복제본 2~3개가 위·아래로 0.05~0.1H 어긋나 겹친다(f849–f862).
- **문구 교체 리듬**: 단어 하나(또는 짧은 구) 단위 장면. 장면 길이 0.9~3.2초. 장면 사이 빈 프레임 0~20프레임.

## 엔진 재현 요구사항
1. 원본 17장면 순서 템플릿(등장·유지·퇴장 상태 시퀀스).
2. 상태 렌더러: 흰 채움 / 남색 외곽선 / 회색 단계 / 위·아래 슬릿 / 잔상 복제 / 거대 줌 버스트 / 작은 크기에서 확대 / 넓은 크기에서 수축.
3. **불규칙 스트로브**: 1~3프레임 간격, 장면마다 다른 패턴(결정적 난수).
4. 배경 수평 노이즈 조각·1프레임 수평 번쩍임·상시 모서리 레이어.
5. 서체: 아주 넓은 초굵은 고딕. 한글은 번들 Pretendard ExtraBold를 가로 1.35배로 늘려 근사한다.
