# 57523104 프레임 단위 사양 (30fps, 1073프레임, 35.8초)

판독 근거: 1프레임 단위 시트 22장 전체.

## 전역 특징
- **배경**: 거의 검정(#050505) + 아주 어두운 연기 줄기(회색 가는 곡선, 10% 이하)가 천천히 흐름 + 그레인. 좌상단 작은 필기체 서명, 우상단 작은 ✦ 표시, 하단 양쪽 아주 작은 글자.
- **글자**: 흰색 압축(condensed) 고딕, 대문자. **줄마다 굵기가 다르다**: 굵은 줄(Black)과 가는 줄(Light)을 섞는다. 줄간격이 매우 좁아(0.82em) **줄끼리 살짝 겹친다**. 블록 폭은 줄마다 다르고 가운데 정렬.
- **모션 블러가 핵심 질감**: 움직이는 글자는 이동 방향으로 강하게 번진다(가로·세로·회전 모두).
- **리듬**: 장면당 2~3.5초. 단어가 **사방에서 다른 방향·다른 속도로 날아와** 블록을 이룬다 → 0.5~1초 정지 → 퇴장. 장면마다 진입 방향 조합이 다르다.

## 엔진 재현 요구사항
1. 장면 12개 템플릿. 장면마다 줄별 진입 방향·지연 조합과 퇴장 조합을 원본대로.
2. 줄별 굵기 교대(Black/Light), 겹치는 좁은 줄간격(0.82em), 압축 서체(Pretendard를 가로 0.86배).
3. 이동 방향 모션블러(속도에 비례), 회색 반투명→흰색 정착, RGB 글리치 복제, 글자 단위 솟음, 단어별 크기 차이 정착.
4. 배경 연기 줄기 + 그레인 + 모서리 작은 표시.
