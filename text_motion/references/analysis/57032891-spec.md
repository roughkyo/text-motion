# 57032891 프레임 단위 사양 (60fps, 2769프레임, 46.2초)

판독 근거: 1프레임 단위 시트 40장 전체. 프레임 번호는 원본 기준(0부터). 60fps이므로 1프레임 = 0.0167초.

## 전역 특징
- **장면 9개, 장면당 4~8초**: 등장 0.6~1.0초 → 오래 유지(미세 흔들림) → 0.3~0.5초 퇴장 → 0.1~0.4초 빈 배경. 장면마다 배경 색이 바뀐다.
- **서체**: 둥글고 아주 두꺼운 디스플레이 서체(대문자, 획 끝이 둥금). 글자마다 **3D 압출**: 앞면은 위 흰색→아래 연회색 베벨, 아래·오른쪽으로 짙은 회색 두께(글자 높이의 약 12%).
- **색 체계**: 강조 줄은 왼쪽 첫 글자가 진한 원색(빨강 #e8202a / 남색 #2030c8)이고 오른쪽으로 갈수록 파스텔 → 흰색으로 바뀌는 **글자 단위 가로 그라데이션**. 나머지 줄은 흰색.
- **줄 배치**: 2~3줄을 줄간격 0.95em으로 빽빽하게 쌓는다. 줄마다 글자 크기·폭이 달라 비정형 블록이 된다.
- **배경**: 거의 검정 바탕에 한쪽 모서리 방사광(장면마다 빨강·남색·보라·청록·파랑·청록 격자) + 필름 그레인·스크래치. 하단 0.93H에 아주 작은 문구 1줄.
- **유지 중 미세 3D 흔들림**: 정착 후에도 블록 전체가 ±3° 안에서 천천히 기울고(원근 포함) 1~2% 크기 변화.
- **퇴장은 장면마다 다르다**: 기울며 아래로 낙하 / 등장의 역재생 / 기울며 오른쪽으로 밀려남 / 겹쳐 모이며 사라짐 / 아래로 빠짐 / 두 줄이 반대 방향으로 날아감.

## 엔진 재현 요구사항
1. 원본 장면 9개를 순서대로 배치하는 장면 템플릿. 장면마다 다른 등장·퇴장·배경을 쓴다.
2. 글자 단위 3D 압출 + 베벨 그라데이션, 줄 단위 원색→흰색 가로 그라데이션.
3. 글자 단위 변환(위치·크기·회전·투명도·블러·자간)과 블록 전체 3D 기울기(원근).
4. 반사, 가로 모션블러, 겹친 덩어리→펼침, 잔상 연쇄 타이핑, 역재생 퇴장, 두 줄 반대 방향 퇴장.
5. 둥근 초굵은 서체: 설치된 한글 둥근 굵은 서체(배민 주아체, 카페24 써라운드 등)가 있으면 쓰고, 없으면 번들 Pretendard ExtraBold로 대체한다.
