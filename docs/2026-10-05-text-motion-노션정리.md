# 샘플 영상 분석으로 만드는 text_motion 스킬

- 2026-10-05 기준, Codex와 함께 제작·수정한 샘플 기반 텍스트 모션그래픽 스킬의 작업 기록임.

## Ⅰ. 제작 목표

- PDF·MD·PPTX·HWPX 등의 소스를 짧은 텍스트 중심 영상으로 제작함.
- 전문가가 만든 원본 영상 10개를 기준으로 텍스트 움직임·전환·배경 흐름을 재구성함.
- 사용자의 선택을 줄이고, 반복 작업은 스크립트로 처리하는 속도 중심 워크플로를 목표로 함.

## Ⅱ. 스킬 사용 흐름

### 2-1. 소스·샘플·길이 선택

- 사용자가 소스 문서를 제공하고 브라우저에서 원본 영상의 썸네일·재생 화면을 확인한 뒤 하나를 선택함.
- 영상 길이는 15초, 30초, 50~60초, 직접 입력 중 선택함.
- 선택 완료 시 브라우저 탭을 닫아 달라는 안내가 표시되고, Codex가 선택한 길이에 맞춰 문구량과 장면을 구성함.

### 2-2. 음악·미리보기·최종 생성

- Codex가 스토리보드와 주제에 맞는 Pixabay 음악 후보를 준비해 검토 화면으로 제공함.
- 음악은 상업적 무료 이용 근거, 주제 적합성, 묵직하고 트렌디한 urban 힙합 비트를 기준으로 검토함.
- 사용자가 음악과 수정사항을 선택하고, 수정된 미리보기를 승인하면 MP4를 생성함.
- 음악 포함 30fps 미리보기와 최종 출력에 같은 렌더러를 사용함.

## Ⅲ. 샘플 분석과 개선 과정

### 3-1. 속도감과 모션

- 원본 10개, 총 12,737프레임과 182개 주석 구간을 분석 자료로 활용함.
- 긴 정지 구간을 줄이고 글자·단어·줄 단위 등장, 확대·축소, 자간 변화, 블러, 잔상, 퇴장을 샘플별로 구분함.
- 선택한 영상 길이에 맞춰 원문에서 문구를 추가하거나 줄여 구성함.

### 3-2. 배경·텍스트 오류 수정

- 모든 샘플에 공통 적용되던 스네어 색 반전을 제거하고 원본별 배경 시간표를 연결함.
- 원본 배경이 지속되면 지속하고, 전환되면 전환 순서와 구간 비율을 따르도록 수정함.
- 같은 배경색의 재등장을 영상 루프로 간주하지 않으며 임의의 왕복 반복을 제거함.
- 단순 타이핑에 섞이던 선택 박스·색 채우기를 분리하고, 선택형 샘플에만 해당 효과를 남김.
- 원본 글자가 남던 연기 배경을 재처리하고 개인 경로와 제작 자료를 배포 패키지에서 제외함.

## Ⅳ. 일본 관광 PDF 테스트

- 일본 관광 가이드북 PDF 32페이지에서 도시·예술·전통·먹거리·자연·온천·료칸을 골라 24장면으로 구성함.
- 보라 연기 샘플 `60806086.mp4`와 기존 선택 음악을 사용해 30초 영상을 제작함.
- 1920×1080, 30fps, 900프레임, 음악 포함 여부와 전체 디코딩을 확인함.
- 배경·타이핑 관련 회귀 검사 13개를 통과했으며, 실제 출력 프레임의 한글과 배치를 점검함.
- 연기 글자 제거 과정에서 질감과 밝기가 원본보다 부드럽고 어두워지는 한계가 있음.
- 원본 AE 프로젝트·전용 폰트·3D 플러그인의 완전 복제는 아니며, 킥·스네어 검출도 자동 추정임.
